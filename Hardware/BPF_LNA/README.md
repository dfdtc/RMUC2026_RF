### 简介

    这是一个简单的预选带通滤波器+LNA，关键器件是带通SAW滤波器B39431B3710U410，和LNA QPL9547；

    本设计期望使用一个比较优质的前置低噪声，降低系统噪声系数，使用预选滤波器，尽可能避免带外大信号干扰（但注意，无法过滤干扰源信号）；

    本设计由TypeC供电5V，实测工作功率<1W，支持从GH1.25受电或给其他设备串联供电，如果不需要可以不焊接。


### Tips

    SMA是板侧装*宽脚*型，普通型号可能勉强能安装，但是不太推荐。
